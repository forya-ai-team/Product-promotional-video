## 8. 验收

参考图降采样到 1920×932 后与窗口区域逐像素比对（ΔE2000，`scripts/diff-refs.mjs`）：

| 指标 | 结果 |
|---|---|
| 原始 ΔE>5 占比 | 4.436% |
| 排除高对比边缘 2px 晕染后 ΔE>5 | **0.000%** |
| 平均 ΔE / 最大 ΔE | 1.425 / 93.94 |
| 分区原始占比 | 左栏 3.449% / 主区 4.731% / 右栏 1.800% |

原始指标未达 AGENTS §6.4 的 1.5%，原因与处理见 D10：参考图是带编解码晕染的录屏帧，94.7% 的超标像素落在高对比边缘 2px 内；结构/配色误差为 0。产物：

- `out/qa/S03-static-f0.png`（成图）
- `out/qa/diff/S03-side-by-side.png`（左参考 / 右复刻，敏感列已遮罩）
- `out/qa/diff/S03-heat-structural.png`（仅非边缘差异；为空即结构对齐）
- `out/qa/diff/S03-ref-window.png` / `S03-shot-window.png`

复现：

```bash
npx remotion still src/index.ts S03Static out/qa/S03-static-f0.png --frame=0
npm run qa:diff
```

## 10. S03 动效：点击 → 波纹 → 顶部特写 → 数据流滚动 → crane-rise-reveal（2026-10-28）

composition：`S03`（352f / 11.7s）；`S03Static` 保留为纯静态基准与像素 diff 用。

| 帧 | 事件 |
|---|---|
| 0–24 | 空列表 hold：0 行、计数 `(0)`、滚动条隐藏、表头勾选为空（动画场景共 90 行，为截图行数的 3 倍；静态基准仍用 30 行） |
| 24–58 | 大指针（46×72）沿二次贝塞尔从 (1320,800) 移到卡片中心 (172.5,309.5) |
| 58–64 | 悬停仅提亮 + 柔蓝投影（无描边/白圈）→ 按下（卡片 scale 0.988、指针缩到 0.88），64f 点击 |
| 64–128 | 圆波纹：3 圈分别 64/74/84f 起，44f 内半径 24→844；4px 亮蓝描边 + 22/70px 双层泛光，外圈加亮蓝底光；白色冲击环与泛光**仅在点击帧起渲染**（点击前无圈） |
| 68–112 | 可见 18 行瀑布式加载：行 i 起始 = 68 + 38 × (1 − (1 − i/17)^2.2)，间隔从 ~4.8f 递减到 ~1f（加速）；行向下 10px 滑入；计数 0→90 同期加速；112f 表头勾选；104–122f 滚动条淡入（90 行 → 160px 短滑块） |
| 88–132 | 相机 1→3.6 推入（bezier(0.4,0,0.2,1)），焦点 (960,540)→(530,330)，停在列表顶部（表头 + 前 6 行，页面标题已出画） |
| 132–156 | 顶部特写 hold 24f，scale 3.6→3.654（+1.5% 呼吸） |
| 156–256 | 数据流滚动 100f：表体在 sticky 表头下向上滚过整张 90 行列表（最大偏移 3056.5px ≈ 72 行），easeInOut(cubic)；滚动条滑块同步从顶部移到底部 |
| 150–274 | 行边缘发光：每行 inset 1px 蓝边 + 18px 内辉光 + 4% 蓝底，强度 0.72；随滚动淡入，滚动结束后淡出 |
| 232–322 | 相机回正 90f（滚动结束前 24f 开始）：3.654→1，焦点回 (960,540)，窗口投影 0.6→1 |
| 322–352 | 落定 hold 30f：全窗停在列表底部（最后 18 行），计数 90，滑块在底部 |

镜头卡：`crane-rise-reveal`（`vendor/video-shotcraft/demos/opening/crane-rise-reveal/CraneRiseReveal.tsx`，pin `43bd349`）。保留：特写 hold → 共用一条不对称缓动的拉升、translate = 屏心 − 对准点×scale、阴影抬升、≥30f 落定。改编（D12）：起点 3.6×（卡为 3.0×）、拉升 90f（卡为 102f）、新增 1→3.6 推入作为顶部特写建立段；用“数据流滚动 + 每行边缘发光”替代原卡的越线行洗光；取消“非追踪行 38% 压暗 / 追踪点 / 状态胶囊 / KPI / 背景点阵”；未使用 CameraMotionBlur。
