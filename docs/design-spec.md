## 14. S05 动效：聚焦消息请求行 + 数字加速膨胀（2026-10-28）

composition：`S05`（450f / 15s，D29）；承接 S05 静态（D24 / D26），窗口 chrome、侧栏、右栏不变，只驱动相机、两个计数与镜头抖动。用户指令：“视角慢慢聚焦 Message requests 附近，250 越长越多，左上角 203 也随之增长，速度越来越快，镜头随涨幅抖动越快，越来越激昂”；甲方后要求保留 15s 并将爆发前移（D29）。

### 14.1 相机

| 段 | 帧 | 运动 |
|---|---|---|
| 起幅 | 0–4 | 全窗 1920×1080，scale 1 |
| 推近 | 4–120（3.9s） | scale 1→2.75，焦点 (960,540)→(660,310)，`inOut(sin)`；画面同时容纳页头 `TikTok / Messages 203` 与请求行 |

### 14.3 抖动（随涨幅）

- `rate = requests(f) − requests(f−1)`；`I = clamp01(rate/900)^0.75`；计数开始后 18f 内按 `gate` 淡入。
- 位移 `gate·(2 + 11·I^1.25)` px：一开涨就有约 2px 的轻微基础抖动（聚焦阶段可见），随涨幅升到 13px（x/y 各两层正弦，权重 0.62/0.38、0.6/0.4）；旋转 `gate·(0.05 + 0.4·I^1.2)` deg。
- 相位用二次 chirp：`φ = 0.7f + 0.0026f²`，起爆前 ≈2.4 rad/帧（≈11.5Hz），叠加 1.37×/1.59× 谐波；涨得越快 → 幅度越大、频率越高。
- 330f 起爆后进入慢动作：8f 内位移压到 12%、旋转同比，chirp 相位速率降到 0.22×（≈11.5Hz → 2.5Hz），之后保持轻摆到片尾——抖动让位给缓慢绽放的火花。
- 抖动作用于整画面（相机层外层），不是逐元素抖动；文字与窗口一起晃，保持“镜头震”的读法。
