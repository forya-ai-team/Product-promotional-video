### 14.3 抖动（随涨幅）

- `rate = requests(f) − requests(f−1)`；`I = clamp01(rate / SHAKE_RATE_REF)^0.75`，其中 `SHAKE_RATE_REF = rate(330) = 3.39`（局部帧 330 = 成片 420f），即**起爆帧的涨幅**——抖动的峰值对齐爆发而不是计数终点，起爆之后本就被慢动作压掉；计数开始后 18f 内按 `gate` 淡入。静止段 `gate = 0` → 位移与旋转解析值精确为 0，不是“近似不动”。
- 位移 `gate·(2 + 11·I^1.25)` px：一开涨就有约 2px 的轻微基础抖动（聚焦阶段可见），随涨幅升到 13px（x/y 各两层正弦，权重 0.62/0.38、0.6/0.4）；旋转 `gate·(0.05 + 0.4·I^1.2)` deg。实测：114f 2.0px → 210f 3.1px → 330f 6.6px → 390f 10.4px → 420f（起爆）13.0px / 0.45°。
- 相位用二次 chirp：`φ = 0.7f + 0.0026f²`，起爆前 ≈2.4 rad/帧（≈11.5Hz），叠加 1.37×/1.59× 谐波；涨得越快 → 幅度越大、频率越高。chirp 只跟局部帧号走，不随数值区间或静止段长短缩放。
- 420f 起爆后进入慢动作：8f 内位移压到 12%、旋转同比，chirp 相位速率降到 0.22×（≈11.5Hz → 2.5Hz），之后保持轻摆到片尾——抖动让位给缓慢绽放的火花。
- 抖动作用于整画面（相机层外层），不是逐元素抖动；文字与窗口一起晃，保持“镜头震”的读法。
