## 本次新增

### D7 VPN 列使用测试网段假数据

- **决定**：参考图中的真实代理 IP / 端口替换为 RFC 5737 文档网段（`192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24`），端口保留原结构；配置名称保留。
- **理由**：IP + 端口属于可被直接利用的基础设施信息，不应进入成片或仓库（AGENTS §6.7）。
- **影响**：VPN 列文本长度略有差异，diff 对该列做遮罩；并排图里参考侧该列已涂灰。
- **确认人**：Agent 按手册执行；用户如要求原样数据需明确推翻本条。

### D8 1920×932 窗口 1:1 放进 1920×1080 舞台

- **决定**：窗口不缩放，上下各留 74px 舞台背景；窗口方角。
- **理由**：AGENTS §6.5 要求非 1080p 窗口按整数倍展示、不拉伸；参考图为最大化窗口，方角是真实形态。
- **影响**：成片会出现上下两条暗色背景带；后续镜头可用 2.5D 相机推进窗口局部。

### D9 品牌图形用截图贴片，字体用系统雅黑

- **决定**：Tolink logo、窗口小图标、左侧 5 个入口图标、右侧 9 个入口图标、折叠箭头从 2x 截图裁切为 PNG；文字与控件全部 DOM。字体使用系统 `Microsoft YaHei`（不内嵌）。
- **理由**：缺少官方 SVG；这些是复杂品牌图形，按 AGENTS §6.2 归入 texture zone。系统字体与参考图一致，避免引入授权问题。
- **影响**：贴片放大超过 2x 会糊，hero 镜头不把镜头推到这些贴片上；渲染机需 Windows 才能保持字体一致。

### D10 参考图为压缩录屏帧，验收同时报告边缘容差指标

- **决定**：像素 diff 同时输出原始口径与 edge-tolerant 口径（排除高对比边缘 2px 内的编解码晕染），以 edge-tolerant ≤1.5% 作为结构性门槛；原始口径如实记录，不通过加模糊/发光伪造。
- **理由**：参考图底部有录制时间水印、顶部有 2px 采集黑边，按钮与文字外围有 2–4px 彩色晕染；原始 ΔE 无法达到 §6.4 的 1.5%，而 94.7% 的超标像素都落在边缘晕染内。将压缩伪影复刻进成片会降低画面质量。
- **影响**：raw 4.436%，edge-tolerant 0.000%，mean ΔE 1.425；产物见 `out/qa/diff/`。此例外需用户确认。

### D11 省略录屏指针与时间水印

- **决定**：不渲染参考图左下角的时间水印与操作系统鼠标指针；指针用自绘 `<CursorGlyph>` 放在截图中的相同位置，后续动画统一由 Cursor 组件驱动。
- **理由**：两者都是录屏工具/系统产物，不属于产品 UI；水印会暴露录制时间。
- **影响**：diff 对这两个区域做遮罩；成片中的指针形态是可替换的 SVG。

### D12 crane-rise-reveal 的叙事改编

- **决定**：在“点击卡片 → 波纹 → 列表出现”的场景里复用 `crane-rise-reveal`，但把起点改为 3.6×、拉升改为 90f，并在波纹期间增加 1→3.6 的推入建立顶部特写；特写向下滚过整张 90 行列表（sticky 表头，滚动 100f），滚动中每行加边缘蓝光；滚动结束前 24f 相机开始回正。取消原卡的 38% 压暗、追踪点、状态胶囊、KPI 与背景点阵、越线行洗光；未引入 `@remotion/motion-blur`。
- **理由**：原卡是“从产品细节开场到整页”的定场镜头，本场景是窗口已在画面内的中段揭示；用户要求先聚焦最上方数据、向下滚动数据流、结尾回正，并用行边缘发光替代洗光。90 行列表让数据流有足够长度；滚动条同步移动。
- **影响**：S03 相机 1→3.6→1，特写 hold 24f、滚动 100f、回正 90f、落定 30f；终帧停在列表底部（最后 18 行，滑块在底），`S03Static` 仍为 30 行顶部状态；需用户确认为可接受的改编。
- **确认人**：Agent 起草；待用户确认。

### D13 列表空态 / 加载态语义

- **决定**：点击前列表 0 行，工具栏计数显示 `(0)`、表头勾选为空、滚动条隐藏；点击后可见 18 行按加速曲线自上而下瀑布式出现（间隔 4.8f→1f），计数 0→90 同期加速、表头勾选与滚动条随后补齐。动画场景使用 90 行（截图的 3 倍，新增 60 行同为 TEST-NET 假数据），滚动条滑块按 90 行缩短为 160px，并随数据流滚动移到底部；特写滚完整张列表后，终帧停在底部（最后 18 行）。`S03Static` 仍使用截图对应的 30 行、顶部位置与 625px 滑块，像素 diff 不变。
- **理由**：空表配 `(30)` 会自相矛盾；这些状态变化是动效叙事所需的最小补充，不引入新功能或新文案。
- **影响**：`MainArea` 增加 `rows` / `rowReveal` / `scrollbarOpacity` / `scrollbarThumbHeight` / `count` / `headerChecked` 受控参数；`S03Static` 使用 30 行默认值，像素 diff 不变。
- **确认人**：Agent 起草；待用户确认。
